# Airesto — Страница просмотра бронирований

Тестовое задание: страница просмотра бронирований ресторана на Vue 3 + TypeScript.

## 🚀 Демо

**[→ Открыть приложение](https://ark-task.netlify.app/)**

---

## Реализованный функционал

### Основные требования
- **Получение данных из API** — `GET https://hh.frontend.ark.software/api/booking`
- **Переключение даты** — навигация по доступным дням
- **Фильтрация зон** — включение/отключение зон ("1 Этаж", "2 Этаж", "Банкетный зал")
- **Фиксированные заголовки** — столы прилипают слева, время фиксируется сверху при прокрутке
- **Текущее время ресторана** — отображается в таймзоне `Asia/Vladivostok`, не локальное
- **Все типы событий** — заказы (New, Bill, Closed, Banquet) и брони (Живая очередь, Новая, Заявка, Открыт, Закрыт)
- **Правила расположения** — перекрывающиеся события укладываются по уровням
- **Эффект наведения** — tooltip с деталями события

### Дополнительные задания ✨
- **Тёмная / светлая тема** — переключатель в шапке, сохраняется в `localStorage`
- **Скрытие контента** — кнопка сворачивания каждой зоны в таблице
- **Выделение времени и столов** — drag-select по пустой области; кнопка **Создать** появляется при активном выделении
- **Кнопка "Создать"** — выводит в консоль `{ tableIds, startTime, endTime }`
